# 附件上传进度与待关联确认

状态：implemented
类型：bug-fix
Owner：web/src/components/AttachmentTmpUploadModal.vue

## 问题
临时上传与关联对话是两个操作。完成临时上传后显示“已上传”容易被误解为材料已可用于对话；直接关闭弹窗会清空列表，上传中的大文件也缺少进度与取消入口。

## 决策
临时上传或解析成功后显示“上传完成，待添加”或“解析完成，待添加”。主按钮使用“添加到当前对话”，只有关联接口成功才提示已添加。混合成功与失败时只移除已关联项，保留失败项重试。

列表非空时通过关闭按钮、遮罩或 Escape 关闭均先确认，用户可继续添加或放弃并关闭。关联请求执行期间禁止关闭和重复提交。关闭、移除和取消操作终止相应上传；取消后的迟到响应不得恢复文件状态。

上传使用 XMLHttpRequest 字节进度与 AbortSignal，通过现有 apiRequest 统一处理认证、错误脱敏与登录失效。进度 100% 仅表示传输结束，服务器成功响应才进入待添加状态。取消停止浏览器传输，不承诺回滚服务端已收到的临时文件；不会调用关联接口。

## 替代方案
自动关联上传文件会改变当前允许选择 OCR 和移除文件的两阶段流程，因此保留明确的确认操作。模拟计时百分比无法反映实际传输，使用浏览器上传字节事件。

## 后果
未关联文件只在当前弹窗中保存，用户确认放弃后清空；不会跨页面刷新恢复。已有临时对象仍沿用服务端生命周期。本次不改后端接口、上传大小或解析规则。

## 验证
新增传输测试覆盖真实字节事件语义、100% 不提前成功、HTTP 413 与取消。组件回调测试覆盖未添加关闭保护、关联中禁止关闭、放弃清空、取消后的迟到响应，以及原有部分成功与关联失败保留。浏览器验证覆盖明确状态、继续添加、放弃、取消和添加成功后的关闭。

相关测试 33 项通过；前端 lint、生产构建、文档构建和工程契约检查通过。浏览器使用模拟业务接口验证待添加提示、关闭确认置顶、继续添加保留、显式关联和取消后放弃；另用本地慢速 HTTP 接收器验证真实上传进度达到 4% 时取消传输，未写生产数据。全量前端测试 388 项中 380 项通过，8 项为既有 entry_redirect 测试缺少 document 的环境失败。本机无 Docker，未运行后端容器全量测试；本次不修改后端。

独立审查通过。补充负向案例验证取消后立即重试时旧响应不能覆盖新控制器、移除文件后的解析成功不提示或恢复条目、关联请求在途时重复确认不再提交。工程检查器单元测试在 Linux 环境 62 项通过；Windows 本地同测试受符号链接权限和路径分隔符影响有两项环境失败。
