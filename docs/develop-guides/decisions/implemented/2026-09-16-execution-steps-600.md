# Agent 默认最大执行步数调整为 600

状态：implemented
类型：feature
Owner：backend/package/yuxi/agents/context.py

## 问题

长文档审理任务达到原有 300 步上限，用户明确要求将默认上限改为 600。

## 决策

将共享上下文的默认最大执行步数改为 600，继续保留管理员显式配置的优先级。不修改模型上下文、摘要阈值或任务停止机制。

## 替代方案

维持 300 不满足本次要求；取消上限会失去执行边界，因此保留有限的 600 步上限。

## 后果

新执行使用新默认值，已启动任务的配置快照不变。较长任务可执行更多步骤，但提高上限本身不会修复循环调用。

## 验证

BaseAgent 流式和非流式测试直接断言传给图的 recursion_limit 为 600，并保留显式配置 42 的覆盖测试。发布前读取生产 Agent 配置，未发现显式步数覆盖。
