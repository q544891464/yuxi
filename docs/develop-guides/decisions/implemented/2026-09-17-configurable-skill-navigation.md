# 管理员维护业务技能导航

状态：implemented

类型：feature

Owner：backend/package/yuxi/services/skill_navigation_service.py

## 问题

业务侧栏的技能入口、排序及绑定需要管理员维护，无需修改前端代码和重新发布。维护者需要了解现有 Skill 权限、引用协议和系统配置存储。

## 决策

“设置 → 侧栏技能”供管理员添加、修改、调整父级、同级排序和删除入口。入口包含中文名称、共享技能 slug、技能显示名、材料说明、结果说明及预设提示词。数组顺序即展示顺序，最多三级、100 个入口。删除入口及子入口不删除技能本体或历史对话。

PostgreSQL config_options 的专用记录拥有当前配置；仓库层锁定记录后检查 revision，旧版本写入返回 409。服务层校验新增或改绑的每个入口，只有原入口未改变的失效绑定可以保留，方便管理员整理其他入口。普通登录用户只能读取；运行时 Skill ACL 仍是调用权限最终边界。配置不会将个人技能发布为共享技能，也不会扩大智能体开放的技能列表。

默认导航由随 Python 包发行的 skill_navigation.json 提供，仅数据库记录缺失时使用；显式保存空数组会保留空菜单。读取错误显示重试，不静默恢复前端硬编码菜单。前端导航 Store 供侧栏、项目新会话及对话引用共同读取；管理员保存后当前页面立即更新，其他已打开页面刷新后读取新版本。已有人工编辑草稿不自动覆盖。消费者侧栏的技能入口、技能添加入口、知识库和数据总览作为项目分组后的独立模块渲染；项目展开或项目新建会话选择器打开时收起技能列表，避免挤占最近对话空间。

## 替代方案

直接编辑 JSON 门槛高且绑定容易出错；新增导航数据表需要不必要的 Schema 变更。专用接口复用已有配置存储，保持通用配置基础字段编辑器不承担树结构语义。

## 后果

共享技能在保存后仍可能被删除、禁用或改变权限，入口会按当前智能体可访问列表显示不可用。相同技能可以被多个业务入口引用，分别提供说明与提示词；技能本体维护继续使用既有技能管理界面。
