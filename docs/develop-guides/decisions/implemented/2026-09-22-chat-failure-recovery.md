# 对话发送与附件失败恢复

状态：implemented
类型：bug-fix
Owner：web/src/components/AgentChatComponent.vue

## 问题
发送失败会清空编辑内容，附件刷新异常会表现为空列表，批量附件部分失败会被成功提示掩盖，通用 HTTP 文案无法指导用户处理业务错误。

## 决策
AgentChatComponent 在当前页面按线程保留未确认发送的原始 payload 与请求编号。明确拒绝的请求允许恢复到输入框；接收状态未知时，恢复操作先查询服务端 Request，存在则重新加载会话，不存在才以原请求编号和原参数重发。后端已有 Request 幂等接入拥有防重复执行的最终边界。未解决的失败消息阻止同线程新消息发送，但不阻止停止运行中的任务。

附件 GET 失败保留缓存并显示重试，版本号防止旧响应覆盖新列表。已成功 DELETE 的附件保持移除；DELETE 失败恢复缓存。AttachmentTmpUploadModal 按文件记录上传失败并支持原文件重试，确认成功只移除本批已关联项，失败项继续留在弹窗。

技能路由把已知输入错误转换为有限业务码，未知错误使用安全通用码。前端只在技能路径和允许状态码上使用白名单文案，其余错误保持脱敏。服务异常使用面向用户的恢复提示。

## 替代方案
无条件恢复输入并使用新编号重发会造成重复执行。直接展示异常可能暴露内部路径。两者均不采用。附件刷新失败将缓存清空无法区分空列表与网络故障，因此保留最后可信状态。

## 后果
未确认的发送仅在当前页面会话内保留，不跨页面刷新持久化。未知状态必须先核对，避免用户在结果未确认时另行创建重复任务。上传失败文件继续占用弹窗内存，关闭弹窗后释放。业务文案白名单需要随新增错误码维护。

## 验证
前端回调测试覆盖查询到已接收请求不重发、未找到时复用原 payload、核对失败不重发、业务拒绝保留输入、切换线程隔离、附件失败与过期响应、批量部分失败及关联失败。API 边界测试继续验证未知响应与认证信息不泄露。后端路由测试覆盖结构化技能错误和未知路径脱敏。

独立容器内三个真实 HTTP 上传请求通过实际技能解析入口验证格式错误、缺少配置头和缺少用途说明；不写生产数据。浏览器在本地页面使用模拟失败接口验证部分上传失败保留、逐项重试、附件刷新恢复、发送核对不重复，以及 HTTP 400 和 HTTP 200 业务拒绝后恢复输入。未进行真实模型调用。

相关前端测试 24 项、后端路由测试 19 项通过，前端 lint、生产构建、文档构建与工程契约检查通过。全量前端测试 383 项中 375 项通过、8 项失败，失败集中于既有登录跳转测试缺少 document 的 Node 环境；该问题在本变更前已复现，不作为本次验证通过项。
