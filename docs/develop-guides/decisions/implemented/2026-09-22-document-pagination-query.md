# 文书分页沿用已显示列表的查询

状态：implemented
类型：bug-fix
Owner：web/src/components/FormalDocumentCenter.vue

## 问题

文书搜索框允许先编辑再提交。加载更多读取编辑中的条件，将另一查询的结果追加到现有列表；搜索失败后继续分页也使用失败的条件。组件函数回归测试三个场景均能恢复缺陷。

## 决策

每次成功替换列表时保存该列表的分类和搜索条件，加载更多只使用保存的条件。搜索失败不更新列表及其查询。保留现有显式搜索、分页和错误提示，不改变后端授权或查询接口。

## 替代方案

输入文字就清空列表并自动搜索会改变现有交互且增加请求；编辑时禁止分页会阻止用户继续浏览现有结果。
