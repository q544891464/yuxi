# 附件删除以服务端确认更新列表

状态：implemented
类型：bug-fix
Owner：web/src/components/AgentChatComponent.vue

## 问题

连续删除附件 A、B，B 成功后 A 失败，会将 A 操作前的整个列表恢复，导致界面重新显示已删除的 B，并可能丢失期间新添加的附件。

## 决策

等待删除接口成功后，仅从当前会话列表移除目标文件，再刷新服务端状态。失败保留当前列表并提示错误。目标是隔离并发删除的失败影响；不修改后端删除语义、上传流程或权限。

## 替代方案

为乐观删除维护每文件回滚与并发状态增加状态管理成本；仅恢复目标文件仍可能恢复已经被另一操作删除的同一文件。串行阻止所有附件操作会限制无关文件的操作。

|---|---|---|---|---|---|
| 删除失败不恢复已删除文件或丢失新附件 | 旧快照覆盖当前列表 | AgentChatComponent.vue | chatFailureRecovery unit 与浏览器隔离交互 | B 成功、A 失败并在期间添加 C | Passed：unit；浏览器覆盖 B 成功后 A 失败，不包含新增 C |

## 后果

慢请求期间附件继续显示；服务端确认后消失。网络不确定失败保留列表与错误提示，后续列表刷新提供服务器事实。
