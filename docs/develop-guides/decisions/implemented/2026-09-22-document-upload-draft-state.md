# 上传文书保留当前办理草稿

状态：implemented
类型：bug-fix
Owner：web/src/components/FormalDocumentCenter.vue

## 问题

连续上传正式文书时，上传响应复用打开详情的初始化逻辑，将用户当前勾选替换为历史提交清单并清空办理意见。浏览器复现上传两份文件后仅第二份保持勾选，容易漏交材料。

## 决策

上传成功更新服务端详情并在当前清单中加入新文件，保留办理意见和用户对旧版的取消勾选；重置已核对确认。打开另一文书或刷新详情仍按服务端历史初始化。上传失败保持草稿不变。

## 替代方案

每次自动选择全部文件会重新勾选被用户替代的旧版；持久化未提交草稿超出本次上传交互修复范围。
