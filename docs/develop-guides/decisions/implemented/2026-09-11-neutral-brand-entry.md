# 中性品牌与直接登录入口

状态：implemented
类型：feature
Owner：web/src/router/index.js

## 问题

独立部署使用知识管理平台名称，用户需要直接进入登录或智能体界面，不展示项目推广内容。

## 决策

用户已明确指定品牌移除和入口行为；实现复用现有身份守卫，不引入新的权限、持久化或路由机制，也无待裁决方案。依照小而完整修复可直接记录 implemented 的约定，保留当前决定，不补造实现前的 proposal。

根路由跳转 `/agent`，由现有身份守卫将未登录用户导向 `/login`。品牌默认值由 `backend/package/yuxi/config/static/info.template.yaml` 拥有，内置聊天提示词使用中性名称。侧栏 GitHub 入口和设置页 Star 卡片移除，登录页采用无大图的居中单栏。

## 替代方案

保留欢迎页并隐藏部分品牌元素仍会增加进入应用的步骤；仅用 CSS 隐藏推广内容保留了无用请求。因此直接调整路由并删除相关展示及请求逻辑。

## 后果

根路径不再展示欢迎页；身份与权限仍由既有守卫和后端执行。登录表单及初始化流程保留。源项目许可和版权文件保留。

## 验证

`web/test/unit/entry_redirect.test.js` 覆盖未登录、已登录、过期会话和登录回跳。部署环境前端 lint、322 项单元测试及生产构建通过；浏览器检查桌面和手机登录布局，服务 readiness 正常。后端单元测试记录为 1929 passed、52 skipped。

Windows 工程检查单元测试存在符号链接权限和路径分隔符差异，使用部署服务器的 Linux 环境复核。真实模型对话及向量接口连接在部署后单独验证，未以页面检查替代业务验证。
